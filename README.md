# Satriyo Portfolio

Portfolio website built with React + TypeScript + Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production files will be generated in `dist/`.

## GitHub Pages

Create a repository named exactly:

`satriodone500-hash.github.io`

Then push this project to that repository.

In GitHub:
Settings → Pages → Build and deployment → Source → GitHub Actions.

For a user-site repository (`USERNAME.github.io`), Vite can use the root path without a special base configuration.

## Customize

Edit `src/App.tsx` for:
- profile text
- projects
- experience
- links

Edit `src/styles.css` for the visual style.
